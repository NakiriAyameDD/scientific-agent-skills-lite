# Scientific Agent Skills Plugin (Core Science & ML Edition)

**Scientific Agent Skills** equips Antigravity with 53 validated research skills focusing on statistics, machine learning, deep learning, high-performance computing, publication-grade visualization, and scholarly writing.

---

## 核心能力概览 (53 项技能)

### 📊 科学统计、试验设计与数据分析 (Statistics & Data Analysis)
- **`statistical-analysis`**: 科学统计假设检验向导（t检验、ANOVA、卡方检验、相关性及 APA 报告）。
- **`statistical-power`**: 样本量估算与统计功效 (Power) 分析（两类错误控制、效应量曲线绘制）。
- **`statsmodels`**: 经典计量经济学模型（OLS、广义线性模型 GLM、自回归 ARIMA）。
- **`pymc`**: 贝叶斯统计推断与马尔可夫链蒙特卡洛 (MCMC NUTS) 采样。
- **`scikit-survival`**: 生存分析与右删失时间至事件 (Time-to-Event) 预测建模。
- **`pymoo`**: 多目标进化优化算法（NSGA-II, MOEA/D 等），非支配解集帕累托前沿搜索。
- **`experimental-design`**: 科学试验方案设计（因素筛选、正交试验、区组化与随机化）。
- **`exploratory-data-analysis`**: 本地科学数据探索性分析 (EDA) 与缺失值审计。

### 🤖 机器学习、深度学习与科学计算 (ML, AI & Scientific Computing)
- **`scikit-learn`**: 通用经典机器学习全流程（特征工程、监督/无监督算法、Pipeline）。
- **`pytorch-lightning`**: 结构化深度学习训练框架（多卡 DDP / FSDP 分布式扩展）。
- **`transformers`**: Hugging Face 大语言模型与多模态模型管道推理与微调。
- **`torch-geometric`**: 图神经网络 (PyG) 拓扑节点与图级分类。
- **`networkx`**: 复杂网络动力学、图论最短路、网络中心度与社群发现。
- **`aeon`**: 专业时间序列机器学习（分类、时间序列聚类、异常检测）。
- **`timesfm-forecasting`**: Google TimesFM 零样本高精度时间序列预测。
- **`shap`**: 机器学习模型全局与局部可解释性分析（Shapley 归因分解）。
- **`stable-baselines3`**: 强化学习标准算法套件 (PPO, SAC, DQN, TD3)。
- **`pufferlib`**: 高性能大规模向量化强化学习环境与训练框架。
- **`umap-learn`**: 高维流形非线性降维与 2D/3D 可视化嵌入。
- **`simpy`**: 离散事件过程仿真系统，用于排队论与资源并发模拟。
- **`dask`**: 突破单机内存限制的大规模分布式 NumPy/Pandas 数据流处理。
- **`polars`**: 现代超高速多线程向量化 DataFrame 计算引擎。
- **`vaex`**: 百亿行级海量大表格极速核外处理与统计计算。
- **`zarr-python`**: 分块 N 维稠密/稀疏多维数组云端压缩存储格式。
- **`matlab`**: MATLAB / GNU Octave 科学数值计算与算法实现。
- **`sympy`**: Python 符号微积分、符号方程求解与 LaTeX 公式导出。
- **`optimize-for-gpu`**: NVIDIA CUDA/CuPy 科学代码加速与瓶颈分析。

### 🎨 科技论文插图与可视化 (Scientific Visualization)
- **`scientific-visualization`**: Nature/Science 顶刊级配色、排版、误差带与多面板组合图。
- **`scientific-schematics`**: 科学原理机制图、算法模型架构图与技术流程图绘制。
- **`matplotlib`**: 底层像素级高自由度科研图表定制。
- **`seaborn`**: 统计分布与多变量关系探索性快速绘图。
- **`infographics`**: 结构化科学信息图表制作。
- **`generate-image`**: 概念视觉艺术与 AI 图像合成。

### 📝 学术写作、文献调研与出版辅助 (Scholarly Writing & Publishing)
- **`scientific-writing`**: 科技论文正文结构起草与严谨性论证事实链核验。
- **`literature-review`**: 系统性学术文献综述与跨数据库证据综合分析。
- **`paper-lookup`**: 18 个主流学术库（arXiv, Crossref, OpenAlex, Semantic Scholar 等）统一检索。
- **`paperzilla`**: 前沿学术论文个性化推荐与文献动态追踪。
- **`citation-management`**: 论文 DOI 引用解析与标准 BibTeX 条目批量生成。
- **`pyzotero`**: Zotero 个人与团队文献库接口自动化管理。
- **`peer-review`**: 学术同行评审报告撰写与论文漏洞严谨评估。
- **`scholar-evaluation`**: 论文发展性同行评审与方法学推敲。
- **`research-grants`**: 国家级科研基金申报书规划与撰写。
- **`research-lookup`**: 论文同行竞争性成果与背景证据链深度收集。
- **`venue-templates`**: 顶级会议与期刊 LaTeX 模板规范与排版校验。
- **`latex-posters`**: LaTeX 巨幅学术会议海报排版。
- **`scientific-slides`**: 学术答辩、组会演示幻灯片（PPT/Beamer）制作。
- **`scientific-brainstorming`**: 科学假说头脑风暴与多视角假设反思。
- **`scientific-critical-thinking`**: 科学论据漏洞识别、混杂因素与偏倚批判性分析。
- **`hypothesis-generation`**: 结构化科学假说构建与验证方案设计。
- **`hypogenic`**: 文本驱动的假说生成与反思精炼。
- **`what-if-oracle`**: 多分支科学决策推演与极端情景压力测试。
- **`consciousness-council`**: 多专家视角思辨委员会审议。
- **`dhdna-profiler`**: 逻辑思维风格与认知图谱文本分析。
